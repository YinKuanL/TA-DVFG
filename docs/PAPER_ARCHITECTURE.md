## Section map

| Section | Job | Must contain | Must not duplicate |
|---|---|---|---|
| Abstract | Entire paper in compressed form | problem, method, key evidence, implication | Introduction detail |
| Introduction | Motivate and position | problem, gap, contributions | full protocol detail |
| Related Work | Establish distinction | closest work and exact difference | generic survey |
| Problem Setup | Define setting | access, communication, labels, deployment | method claims |
| Method | Explain mechanism | objective, algorithm, complexity | experimental conclusions |
| Experiments | Test claims | protocols, baselines, evidence | unsupported speculation |
| Conclusion | Close the argument | answer, limits, next step | new evidence |
