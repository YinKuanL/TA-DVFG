# Experiment Status

## Status vocabulary

- PROPOSED: idea only; do not run.
- APPROVED: scope approved; may run exactly as specified.
- RUNNING: currently executing.
- COMPLETE: expected outputs exist and were checked.
- BLOCKED: cannot proceed; reason recorded.
- REJECTED: intentionally not part of the paper.
- ARCHIVED: historical evidence; do not modify.

## Before approving a new run

- [ ] It answers a specific unresolved claim.
- [ ] Existing outputs cannot already answer it.
- [ ] Protocol is matched to the intended comparison.
- [ ] Exact command/config is recorded.
- [ ] Runtime class is acceptable.
- [ ] Output path is new and non-destructive.
